SLIDE 3: PHASE 2 - NOVEL CUSTOM ARCHITECTURE (2 minutes)
====================================================================

Problem with Transfer Learning for this Domain:
1. Black-box: Cannot explain decisions
2. Biased: Predicts majority class to maximize accuracy
3. Generic: Designed for ImageNet, not anomaly detection
4. Inefficient: 5.3M parameters overkill for binary classification

Solution: Custom Hybrid CNN-Attention Architecture

Component 1: SPATIAL ATTENTION MODULE (SAM)
- Purpose: Learn WHERE anomalies occur in spectrograms
- Implementation:
  * Channel-wise pooling (mean + max)
  * Convolutional layer outputs spatial weights
  * Sigmoid activation creates importance map
- Output: 14×14 spatial attention map
- Benefit: Visualization of anomalous regions

Component 2: CHANNEL ATTENTION MODULE (CAM)  
- Purpose: Learn WHICH FEATURES matter
- Implementation:
  * Global pooling (average + max)
  * Shared MLP weights features
  * Sigmoid creates channel importance scores
- Output: 512 channel importance weights
- Benefit: Understand which features detect anomalies

Component 3: FOCAL LOSS
- Problem: CrossEntropyLoss treats all examples equally
- Solution: Focal Loss = -(1-p_t)^γ * log(p_t)
  where γ=2
- Effect:
  * Down-weights easy examples (normal data): (1-0.99)^2 ≈ 0.0001
  * Focuses on hard examples (anomalies): (1-0.3)^2 ≈ 0.49
- Benefit: Model learns to detect anomalies despite imbalance

Component 4: OPTIMAL THRESHOLD TUNING
- Standard: Fixed threshold at 0.5
- Improvement: Find threshold maximizing F1 score
- Adaptive: Threshold learned from validation data

Architecture Diagram:
Input (3, 224, 224)
  → ConvBlock1: 64 channels [112×112]
  → ConvBlock2: 128 channels [56×56]
  → ConvBlock3: 256 channels [28×28]
  → ConvBlock4: 512 channels [14×14]
  → [Channel Attention] × [Spatial Attention]
  → Global Average Pooling
  → FC(512 → 2)
  → Softmax

Key Statistics:
- Parameters: 1.58M (70% smaller than EfficientNet)
- Model Size: 6.3 MB (vs 15.6 MB)
- Training Time: 45 minutes (vs 60-90 minutes)
- Interpretability: FULL (attention maps)

ANTICIPATED QUESTIONS & ANSWERS
====================================================================

Q: "Why is your accuracy lower than transfer learning?"
A: "I'm optimizing for the right metric. Transfer learning maximizes
   overall accuracy (83.90%) by predicting all 'normal'. My model maximizes
   F1-score to actually detect anomalies (recall 68%), which is the real
   business goal. For anomaly detection, catching anomalies matters more
   than accuracy on normal data."

Q: "Why not just use transfer learning with threshold tuning?"
A: "Good point! I could. But transfer learning models are:
   1. Black-box (can't explain decisions)
   2. Massive (5.3M params, overkill for 2-class problem)
   3. Not designed for anomaly detection
   My custom model is all of: interpretable, efficient, purpose-built."

Q: "Is Focal Loss something you invented?"
A: "No, it's from Facebook Research (Lin et al., 2017). But applying it
   here is novel - I identified that extreme class imbalance was the real
   problem and applied the right technique. That's ML engineering."

Q: "How does Spatial Attention differ from just visualizing feature maps?"
A: "Feature map visualization shows what features activated. Spatial
   attention shows which spatial locations matter for decisions. They
   answer different questions: 'What features?' vs 'Where in spectrogram?'"

Q: "Can you compare to other anomaly detection methods?"
A: "I could benchmark against: Isolation Forest, One-Class SVM, autoencoders.
   But that's beyond this scope. My focus was adding novelty to your existing
   deep learning project."

Q: "Would an ensemble do better?"
A: "Probably yes. We could vote between Transfer Learning + Attention models.
   That's future work. But for this project, I wanted to show both approaches
   separately to demonstrate understanding of each."

Q: "Why use spectrograms instead of raw time-series?"
A: "Spectrograms are better for CNNs because:
   1. Convert 1D temporal to 2D spatial
   2. Frequency patterns more obvious visually
   3. Transfer learning models expect 2D images
   It's a common preprocessing in time-series + DL."
