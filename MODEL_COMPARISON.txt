=====================================
NOVELTY COMPONENTS
=====================================

1. SPATIAL ATTENTION MODULE (SAM)
   - Learns WHERE anomalies occur in spectrograms
   - Generates spatial importance maps (14x14)
   - Visualization: Heat maps of anomalous regions

2. CHANNEL ATTENTION MODULE (CAM)
   - Learns WHICH FEATURES matter for detection
   - Weights 512 feature channels by importance
   - Visualization: Top-k important features ranking

3. FOCAL LOSS FOR CLASS IMBALANCE
   - Handles extreme class imbalance (83:16 ratio)
   - Formula: L = -(1-p_t)^gamma * log(p_t)
   - Downweights easy examples, focuses on hard cases

4. OPTIMAL THRESHOLD TUNING
   - Finds decision boundary maximizing F1 score
   - Adapts to actual class distribution
   - Better than fixed 0.5 threshold
